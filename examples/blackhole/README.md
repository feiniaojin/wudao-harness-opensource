# 3D 黑洞引力模拟器

零依赖（仅需联网加载 CDN 上的 Three.js）的单文件 Web 模拟器：**双击 `index.html` 即可运行**。

## 运行方式

- 直接双击 `index.html`（Chrome / Edge / Safari / Firefox 均可，需联网）
- 或本地起静态服务后访问：

  ```bash
  python3 -m http.server 8000
  # 浏览器打开 http://localhost:8000
  ```

## 物理模型

单位制取 `G = 1, c = 1`：

| 量 | 公式 |
|---|---|
| 事件视界半径 | `Rs = 2M` |
| 光子球半径 | `1.5 Rs` |
| ISCO（最内稳定圆轨道） | `3 Rs` |
| 开普勒轨道速度 | `v = √(GM/r)` |

- **积分器**：速度 Verlet（中心力场下角动量精确守恒，长时间模拟无能量漂移）
- **引力**：`F = -GM/r³ · r`，带软化长度 `0.4 Rs` 避免奇点发散
- **吞噬**：粒子越过视界（`r < Rs`）即被移除，并计入黑洞质量（吸积，视界缓慢扩张）
- **初始条件**：吸积盘（86%，近开普勒轨道、喇叭状垂向分布）+ 倾斜晕族（8%，随机轨道面椭圆轨道）+ 内落流（6%，3 条俯冲扇形流）
- **渲染特效**：温度渐变着色（内热外冷）、径向速度多普勒红移/蓝移、光子环、菲涅尔视界边缘微光、吞噬闪光

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 | 旋转 / 缩放相机 |
| 空格 | 暂停 / 继续 |
| 面板滑块 | 粒子数（需重启）、黑洞质量（实时生效）、时间流速 |
| 面板按钮 | 暂停 / 单步 / 重置（换随机种子） |

## 代码结构与验证

- `index.html` 中 `/*__PHYSICS_BEGIN__*/ … /*__PHYSICS_END__*/` 之间是**纯 JS 物理内核**（不依赖 THREE / DOM），渲染层通过 `globalThis.BHPhysics` 调用。
- 验证脚本（提取物理内核在 Node 中运行）：

  ```bash
  node scripts/test-blackhole-physics.mjs
  ```

  覆盖：圆轨道长时间稳定性（半径 / 角动量 / 能量）、视界吞噬逻辑、多粒子无 NaN。
