# @wudao-org/web

The web frontend of [wudao-harness](https://github.com/feiniaojin/wudao-harness) — `wudao ui`: chat with your agent, browse files, manage sessions and memory, and watch the monitoring dashboard (model calls, tool traffic, thinking, token flow).

A prebuilt static bundle, served by `@wudao-org/server`. You don't install this directly — install the app: `npm install -g wudao-harness`, then run `wudao ui`.
