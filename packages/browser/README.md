# @wudao-org/browser

Controlled-browser foundation for [wudao-harness](https://github.com/feiniaojin/wudao-harness): a launch-once Chromium runtime with idle reaping, snapshot refs, and the six browser tools (navigate / read / click / type / scroll / screenshot) the agent uses to work on real web pages.

- MIT license. Part of [wudao-harness](https://github.com/feiniaojin/wudao-harness) — install the whole app with `npm install -g wudao-harness`.
