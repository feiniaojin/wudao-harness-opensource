# @wudao-org/server

The localhost WebSocket server behind `wudao ui` — it connects the wudao agent driver to the web frontend: first-frame auth, live state streaming, and the operating surface (sessions, files, memory, monitoring).

- MIT license. Part of [wudao-harness](https://github.com/feiniaojin/wudao-harness) — install the whole app with `npm install -g wudao-harness`, then run `wudao ui`.
